## 재현 체크리스트

- 개발 빌드 시작 → 두 갤러리 카드가 정적이고 선택 가능.
- 자수 기본 한글이 읽히고 1.6초 뒤 정지. 다시 수놓기 정상.
- 한글 조합 중 편집값 유지. 41자/4줄/emoji 오류. 문구 비우고 재실행해도 빈 상태·공유 비활성.
- 빠른 문구 변경은 최신 결과만 표시. 길어서 배치 불가능하면 오류와 편집 경로, 공유 금지.
- 드래그와 탭 구분, 감상 모드 한 번 탭/접근성 종료 액션.
- 비 위쪽 이동, 일시정지 후 위치 고정, 드래그 효과 복구.
- 공유 중 중복 탭, 공유 취소, 앱 백그라운드/뒤로 가기. 불필요한 재생 재개 없음.
- 출력 두 PNG 1080×1920, UI/워터마크 없음, 화면과 문구·시점·터치 일치.
- Reduce Motion 켜고 시작하면 자동 모션 없음. VoiceOver/TalkBack에서 버튼·현재 문구·감상 종료 접근.

## 알려진 시각/제품 한계 (최대 3)

1. 비는 물리 굴절·방울 병합이 없는 마스크 합성 근사이며 사실적 재료감은 추가 개선 대상.
2. 자수는 손글씨 마스크의 거리장·실결 음영을 이용한 2D 근사입니다. 실제 실 시뮬레이션, 꽃·잎 장식, 자유 곡선 필기는 구현하지 않았습니다.
3. 실제 양 플랫폼 UX/성능은 CI 및 기기 증거 확보 전 출시 수준으로 보장하지 않음. 아이콘도 기본 템플릿 상태.

- 사용자 승인: X 격자 대신 손자수 느낌, 김 서린 창을 손끝으로 닦아 쓴 글씨.
- 참조: https://yangyumzip.vercel.app/app/works/embroidery/index.html 및 사용자가 제공한 이미지. 참조 사이트의 소스·이미지·로고는 복사하거나 번들에 넣지 않았습니다.
- Gaegu Regular/Bold를 공식 Google Fonts에서 받아 OFL과 함께 번들.
- 절차적 린넨, 글리프 실결/음영, 불균일한 김, 흐릿한 창밖, 닦인 글씨 경계, 3.2초 터치 복구. 화면과 PNG는 같은 artwork 함수를 사용합니다.
- 재질 생성은 현재 JS에서 동기 실행합니다. 실제 모바일 편집 응답시간/메모리/프레임률 측정 전이며, CI·기기 검증 없이 성능 통과로 판단하지 않습니다.

## 2026-10-19 참조 화면 기반 재구현 (npm 전환 포함)

- 패키지 매니저: npm(`package-lock.json`). Bun 파일 제거, `npm ci`로 재설치.
- 자수: 글리프 마스크 → 세선화 → 획 중심선을 따라 stem/back/chain/프렌치 노트 스티치(Skia `Atlas`). 작은 ㅇ 고리는 꽃으로 피어나고, 획 끝에는 꽃봉오리·잎. 들꽃/붉은 실/남색 실 팔레트, 세로쓰기(기본)/가로쓰기 전환, 땀 간격.
- 빗물: 보케 배경, 고르지 않은 김, 풍경을 뒤집어 비추는 렌즈 물방울, 획 순서대로 닦이는 글씨와 흘러내린 자국, 아래로 미끄러지는 물방울(`RAIN_DIRECTION = 1`), 3.2초 동안 남는 손가락 자국.
- 발견·수정한 기존 결함: 네이티브 `ParagraphBuilder`에는 `dispose()`가 없어(타입 선언과 다름) 이전 코드도 기기에서 리소스 준비가 실패했을 것. `random()`이 인접 seed에서 거의 같은 첫 값을 내던 문제(seed 스크램블 추가).
- Atlas는 sprites/transforms/colors 길이가 다르면 네이티브에서 abort한다. 프레임별 배열은 고정 길이(달리는 물방울 12, 손가락 자국 40)로 유지한다.
